# Pickflow Web

Panel de control administrativo web de **Pickflow**, construido con Next.js 14 (App Router) y Tailwind CSS.

## Comandos

```bash
# Instalar dependencias
npm ci

# Servidor de desarrollo (puerto 3000)
npm run dev

# Compilar para producción
npm run build

# Iniciar en producción
npm start

# Linting
npm run lint
```
