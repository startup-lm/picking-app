# Pickflow Mobile

Aplicación móvil para operarios de depósito de **Pickflow**, construida con React Native y Expo SDK 54.

## Comandos

```bash
# Instalar dependencias
npm ci

# Iniciar Metro bundler
npm run start

# Ejecutar en Android
npm run android

# Ejecutar en iOS
npm run ios

# Linting
npm run lint

# Typecheck
./node_modules/.bin/tsc --noEmit
```
